使用场景

流媒体与内容访问

旗舰版与团队版强调全节点原生解锁，适合连续观看海外剧集与直播。基础版覆盖常用平台的基础解锁，适合轻度使用。观看前建议先更新订阅并选择标注流媒体的节点。

游戏与低延迟

需要更稳延迟时，优先旗舰版 IPLC 专线。将客户端切换到游戏优化节点，并开启系统代理或 TUN，减少丢包。团队版可按业务把游戏流量与办公流量拆到不同策略。

远程办公与多设备

笔记本、手机和平板同时在线时，对照套餐设备上限。团队版适合共享订阅但仍需独立配置文件的小组，可配合定制路由把内网工具与公网加速分开。

配置流程

按纵向步骤完成一次即可在多端复用同一订阅。全程在客户端内操作，无需额外脚本。

1确认套餐与订阅

在官方渠道选定基础版、旗舰版或团队版并完成开通。账户中会生成机场订阅链接，请复制完整 URL，后续所有客户端都使用同一地址更新节点。

2下载对应客户端

Windows 常用 Clash 系桌面端；macOS 可用 Clash 或 Surge；Android 使用 Clash Meta 类应用；iOS 使用 Shadowrocket 等订阅类客户端。路由器用户将订阅转为对应协议后写入设备。

3导入订阅并更新

打开客户端的订阅或配置页，粘贴 MESL 订阅链接，执行更新。确认节点列表出现后，再开启系统代理。若列表为空，检查链接是否完整、本地时间是否准确。

4选择节点与模式

日常浏览选普通线路；流媒体选解锁节点；游戏选 IPLC 或低延迟专线。规则模式适合分流，全局模式适合需要整机走代理的场景。团队版可按域名做定制路由。

5验证与排障

打开目标站点或游戏确认连通。异常时先更新订阅、更换节点、检查设备数量是否超限。旗舰与团队用户可通过优先工单提交日志，说明客户端名称与错误现象。

客户端下载与导入说明

MESL 官方下载指引以各系统常用客户端为准，安装包请从系统商店或客户端项目发布页获取，本站仅提供订阅导入步骤，避免来源不明的安装文件。

桌面端

Windows 与 macOS 安装完成后，新建订阅，名称可填 MESL，URL 粘贴机场链接，更新间隔建议 12–24 小时。首次连接允许系统代理权限。

移动端

iOS 在客户端内添加 Subscribe；Android 选择 Clash 兼容格式导入。移动网络与 Wi-Fi 切换后如断开，重新点连接即可。注意套餐同时在线台数。

官网下载入口说明

完成套餐后可在用户中心查看订阅与简易导入图示。若应用商店无法搜索到指定客户端，改用同一协议的替代客户端，只要支持订阅 URL 即可连接 MESL 节点。

节点与线路说明

MESL 节点覆盖亚洲主要城市以及北美、欧洲常用出口，普通池适合网页与轻量视频，VIP 与 IPLC 面向高带宽与游戏。高峰时段请避开拥挤节点，优先延迟检测结果更低的线路。不承诺固定 IP，连接以当前可用节点为准。

常见问题

如何在 MESL 获取机场订阅？

选择套餐并完成开通后，在账户或用户中心复制订阅链接。将该链接导入 Clash、Shadowrocket 等客户端并更新，即可拉取 MESL 节点。链接请勿公开分享，以免流量被占用。

各套餐同时在线设备如何计算？

基础版 3 台、旗舰版 5 台、团队版 20 台。同一账号在多端使用同一订阅即计入在线数。超出后可能出现连接被踢或失败，关闭闲置设备后再连。

流量按什么周期重置？

流量按自然月重置。年付只是预付优惠，每月额度仍按套餐标注的 100GB、300GB 或 1000GB 计算。请在客户端或用户中心查看已用流量，避免中途耗尽。

怎样解锁流媒体？

基础版提供基础流媒体解锁；旗舰版与团队版为全节点原生解锁。若仍提示地区限制，更新订阅后更换解锁节点，并关闭可能干扰的本地 DNS 覆盖。

游戏加速应选哪一档？

对延迟敏感的对战游戏建议旗舰版 IPLC 专线。导入后选择游戏优化节点，使用规则或全局模式测试丢包。团队版适合多成员同时开黑并需要独立策略的情况。

客户端下载失败或无法导入怎么办？

先确认应用来源可靠，再检查订阅 URL 是否被截断。导入失败时可更换同协议客户端重试，并核对系统时间。仍失败时向工单提供客户端名称与报错原文。
